ZecPy: Private ZEC for Python.

A Python SDK for shielded Zcash. Its light server sees zero requests that identify the wallet.

Read the quick start

What servers learn

A light wallet asks its server for blocks and tree states. Some questions give the wallet away: its transparent addresses, its birthday, where its last sync stopped. We put a recording proxy between each wallet and its server, ran the same five scenarios, and counted the requests that identify the wallet.

The server's side

ZecPy Live, replaying a recorded run on a local chain: a shop checkout, an agent paying a link, a memo fetch, cold signing. Two audit proxies label every request as it arrives.

The whole API

The whole surface fits on one screen. Everything that touches the network is async; every amount is an integer of zatoshis.

invoices.create

Each invoice gets its own diversified shielded address. Payments match during local trial decryption: no memo, no question to the server.

invoice = wallet.invoices.create(150_000, "order-77")
invoices.watch

Yields detected, confirmed and reverted events. The last state is persisted, so a restart never delivers a payment twice.

async for event in wallet.invoices.watch(confirmations=3): ...
send_many

Up to 50 recipients in one shielded transaction, proved and signed on your machine. A transparent recipient raises PrivacyError.

txid = await wallet.send_many([(addr, 125_000_000, "October")])
propose

The fee, the notes spent, the change, and any amount a pool crossing would make public, before anything is built. Send exactly that with send_proposal.

plan = wallet.propose(addr, 50_000); print(plan.fee, plan.crossing_value)
pay

Pays a ZIP-321 link within a budget. A link asking for more than max_zat, or for no amount, is refused whole: an agent cannot be talked past it.

txid = await wallet.pay(uri, max_zat=200_000)
propose_cold

The server holds a viewing key only. It builds and proves a PCZT; the offline zecpy-cold signer shows what will leave and signs.

pczt = wallet.propose_cold(addr, 50_000)
fetch_memos

Opt-in. Each real transaction is fetched among 7 decoys from nearby blocks, its rank in the set uniform, on a Tor circuit of its own.

report = await wallet.fetch_memos(decoys=7)
transactions

History from the local database only. Listing it sends nothing to the server.

for tx in wallet.transactions(): print(tx.txid, tx.net_value)

No call by that name. Try invoices, send, pay or memos.

Two refusals, on screen

Both from the same recorded run. The server never sees which transactions are ours, and the signer never takes the server's word for what is change.

Clone to paid

Linux, Python 3.10 or newer and a Rust toolchain. The first build compiles librustzcash, so it takes a while once.

from zecpy import Wallet

wallet, mnemonic = await Wallet.create(
    "./shop", network="test",
    server="https://testnet.zec.rocks:443")
invoice = wallet.invoices.create(150_000, "order-77")
async for event in wallet.invoices.watch():
    if event.invoice_settled:
        ship(event.invoice.reference)

What it will not send

  • no t-addrsTransparent recipients raise PrivacyError unless you opt in
  • no fallbackTor or nothing: a fresh circuit for each sync and each send
  • no lone txidEvery memo fetch hidden among 7 decoys
  • no sync trailTree states at aligned heights, never where the last sync stopped
  • no mempoolPayments are seen in blocks, never looked up by txid

For your agent

The docs are also published as plain text for language models. llms.txt indexes them; llms-full.txt is the whole reference in one file. Paste the brief into your agent's instructions, or drop AGENTS.md into your repo.

Agent brief
You are writing Python that uses ZecPy, an SDK for shielded Zcash.
Reference: llms-full.txt on the ZecPy website.

- Network calls are async: await Wallet.create, sync, send, pay.
- Amounts are integers in zatoshis. 1 ZEC = 100_000_000.
- Never print, log or return the mnemonic. Call .reveal() only
  to hand it to the storage the user chose.
- Take payments with wallet.invoices.create and invoices.watch.
  Match by invoice, never by memo.
- Pay links with wallet.pay(uri, max_zat=BUDGET). Never raise
  max_zat to make a payment go through.
- PrivacyError is a refusal, not a bug. Do not pass
  allow_transparent or allow_pool_crossing unless the user
  asked for exactly that.
- Keep tor=True. Use network="test" until told otherwise.
Install it, create a testnet wallet, take your first private payment. Start
